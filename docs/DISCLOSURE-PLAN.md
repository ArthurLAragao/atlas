## Separar staging do repositório público

Proposta: staging recebe somente dist de build local revisado e aviso de terceiros. Não enviar .git, docs brutos, anexos, perfis, backups ou banco de usuário. Código cliente compilado continua inspecionável; enviar apenas dist não esconde literais presentes no runtime, como contextos/placeholder. Uma URL sem divulgação ainda pode ser acessível: acesso restrito é decisão/configuração distinta.

Não há necessidade de publicar o repositório nem fazer push para avaliar o app. Futura criação/link do projeto, upload de dist, controle de acesso e revisões do staging exigem autorização separada. Licença/procedência e referências de runtime pendentes continuam visíveis nos gates; nenhum aceite de performance ou release definitiva.
